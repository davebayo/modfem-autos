# public/fonts/

## Panchang

Real, freely-licensed files from Fontshare (Indian Type Foundry), loaded via
`next/font/local` in `lib/fonts.ts`:

- `Panchang-SemiBold.woff2` (600)
- `Panchang-Bold.woff2` (700)
- `Panchang-ExtraBold.woff2` (800)

Used exclusively for the MODFEM AUTOS brand wordmark (`TopNav.tsx` and
`NavigationDrawer.tsx`) via the `font-panchang` Tailwind utility. Every other
typographic element in the app uses the default `font-sans` (Geist) stack.
